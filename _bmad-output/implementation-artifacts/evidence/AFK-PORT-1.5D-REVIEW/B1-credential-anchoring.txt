# B1 — an embedded credential is accepted, then echoed verbatim

A synthetic, non-live token shape is used throughout. resume_instruction is by
contract a command line, so a credential in it is never at offset 0.

## refusal only when the credential starts the string
    rc=4  offset=0  REFUSED
    rc=2  offset=27  ACCEPTED

## and the accepted one is then disclosed on every status run
    Start the successor ORCH PM session yourself in Orca, then run: claude --resume PM --token ghp_SYNTHETICAAAAAAAAAAA
    resume_instruction: claude --resume PM --token ghp_SYNTHETICAAAAAAAAAAA

## the same anchoring holds for every token alternative; the PEM alternative,
## which carries no ^, is the only one that matches anywhere in a value.
