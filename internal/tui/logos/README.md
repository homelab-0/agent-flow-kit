# Route logos

The 64×64 PNGs drawn in the route rows, the gateway row and the local engine rows on terminals that show images.

Single-colour marks have a light copy (`-light`, for dark terminals) and a dark copy (`-dark`).

- Agent CLIs: `claude`, `codex`, `grok-*`, `ollama-*`, `opencode-*`, `pi-*`, `cursor-*`, `kimi-*`, `vllm`, `copilot`, `agy`, `devin`, `kiro`, `qwen` and `gemini` (the Gemini CLI mark) are rendered from [lobe-icons](https://github.com/lobehub/lobe-icons) v1.106.0 (MIT).
- Gateways and engines from lobe-icons v1.106.0 (MIT): `openrouter-*`, `cloudflare`, `vercel-*`, `openai-*`, `anthropic-*`, `lmstudio-*` and `tgi` (the Hugging Face mark).
- From [Simple Icons](https://github.com/simple-icons/simple-icons) 15.0.0 (CC0): `kong-*` and `envoy` (Envoy Proxy, in its brand colour).
- From [selfh.st/icons](https://github.com/selfhst/icons) (CC BY 4.0): `litellm` and `llamacpp-*`.
- From [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons) (Apache-2.0): `localai`.
- From the projects' own repositories: `sglang` (sgl-project/sglang `assets/logo.png`) and `mlx-*` (ml-explore/mlx `docs/src/_static/mlx_logo*.png`), trimmed and given a transparent background.
- `agentgateway` is cut from the agentgateway wordmark.

Portkey has no logo here, so a Portkey gateway keeps its `GW` text tag.

The marks belong to their owners. AFK shows them only to say where a task is going.
