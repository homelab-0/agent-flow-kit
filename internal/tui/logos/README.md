# Route logos

The 64×64 PNGs drawn in the route rows on terminals that show images.

- `claude`, `codex`, `grok-*`, `ollama-*`, `vllm`, `copilot`, `agy` and `devin` are rendered from [lobe-icons](https://github.com/lobehub/lobe-icons) v1.106.0 (MIT). `grok` and `ollama` are single-colour marks, so each has a light (`-light`, for dark terminals) and a dark (`-dark`) copy.
- `agentgateway` is cut from the agentgateway wordmark.

The marks belong to their owners. AFK shows them only to say where a task is going.
